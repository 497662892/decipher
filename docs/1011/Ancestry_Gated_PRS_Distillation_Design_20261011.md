# 由祖源调节权重的 PRS 蒸馏

最值得先验证的学生，是一个保留年龄/性别基础风险、由连续祖源坐标调节多个 PRS 系数的小模型。祖源信息负责选择和调节遗传信号；个体 PRS 仍是必要输入。仅以 ancestry 预测疾病会丢失同一祖源内的遗传差异，也不能称为多 PRS 整合。

本文件给出下一阶段可执行的设计。本轮 NYU benchmark 已实现同结构思路的真实标签可变系数对照；**尚未训练软标签蒸馏学生**。最终是否值得蒸馏，要同时看教师增量、学生容量和独立的蒸馏收益。

本阶段沿用原定 External PRS 和 official training/development 人群，依据[修正后的同队列结果](NYU_Internal_Analysis_Results_20261011.md)评价教师与学生。之前 QC/亲缘版本的阴性结果仅适用于该敏感性分析，不用于决定原定主线是否成立或强制某疾病优先。首轮学生保留强单 PRS、固定权重及同结构真实标签对照，分别检验压缩、祖源调权和软标签的增量。

## 输入与主学生

令 `Z` 为该疾病的标准化 External PRS 向量，`A` 为原定 10 个连续 PC，`C` 为年龄、合格时的性别。所有缩放参数来自当前训练上下文。部署时输入同定义的 `Z, A, C`，不需要训练集 context 或 TabPFN checkpoint。

当前内部阶段的完整教师与学生均使用提供的 `PC1_sd`–`PC10_sd`，保持教师的既定定义。严格 Disco 匹配比较仍单列使用 1000G refPC。未来需要换用参考投影坐标进行迁移时，另建教师版本并生成对应软标签；该变更不作为当前内部蒸馏的前置要求。六输入学生相对 26 输入教师是明确登记的 PRS 压缩对照，不改变完整教师输入。

建议先训练可稳定优化的有符号模型：

\[
\operatorname{logit}p_S=b(C,A)+\sum_j[\beta_{j0}+\gamma_j^\top A]Z_j.
\]

`b(C,A)` 使用与固定系数对照完全相同的年龄/PC 加性样条和性别项。`γ` 受到比全局系数更强的收缩；当数据不支持祖源调节时，模型可以退回固定系数。固定特征基下，这仍是带正则的 Logistic 模型，可以使用成熟库求解；没有必要先训练复杂网络。

这个模型的 `βj(A)` 是预测系数，允许负值。相近 PRS 高度相关时，单个系数可能不稳定，因此应解释组合后的遗传风险、分数家族贡献及重训练稳定性，而不是将单列系数称为生物学贡献。

## 非负权重学生

若希望直接展示“祖源对应的 PRS 比例”，可采用下式作为独立的受约束学生：

\[
w(A)=\operatorname{softmax}(a_0+GA),\qquad
\operatorname{logit}p_S=b(C,A)+\kappa\sum_j w_j(A)Z_j,\quad\kappa>0.
\]

Gate 仅接收祖源 PC；年龄、性别和 PRS 不进入 gate。先使用线性 gate 和全局尺度 `κ`，并收缩 `G` 向零。只约束 `Σw=1` 而没有 `κ`，会把遗传效应强度不合理地固定住。进一步引入 `κ(A)` 时，需要单独对照，以区分“遗传效应整体变强”和“不同 PRS 相对权重改变”。

按以下顺序增加自由度，保持基础项不变：

| 学生 | 相对权重 | 遗传效应尺度 | 回答的问题 |
|---|---|---|---|
| S0 | 全局固定 | 全局固定 | 固定整合是否足够 |
| S1 | 随 A 变化 | 全局固定 | 祖源权重平衡是否有用 |
| S2 | 全局固定 | 随 A 变化 | 是否只是整体遗传效应强度不同 |
| S3 | 随 A 变化 | 随 A 变化 | 两种变化是否都需要 |

有符号学生与非负学生不能只按漂亮的权重图选择。非负约束可能提高稳定性，也可能限制高相关分数的有效组合。两者的预测能力和保真度都要比较。

T2D 的 25 个 D-PRISM 成分高度相关。主教师可保留完整 26 列；学生首先比较完整 26 列与“5 个公开 metascores + PRS-CSx”六列版本。后者减少 gate 参数，代价是压缩了教师可用的信息。公开 metascore 的成分标准化仍须在每个拟合上下文内重新计算。不得用 development 表现挑选后再把该选择包装成预先指定的主学生。

此前 QC 队列的输入诊断中，T2D 26 列去除参考 PC 的线性成分后，325 个分数对仍有 19 对 `|r|>0.95`、4 对 `|r|>0.99`；前 5 个主成分解释至少 95% 的标准化分数方差。这是敏感性队列中的冗余证据，不能证明六个公开组合能无损保留原定人群的疾病预测信息。诊断数据和图保留于 `outputs/internal_prs/nyu_20261011/score_redundancy/`。

## 教师目标与损失

教师为当前已冻结配置的 TabPFN，其训练上下文限定于学生当前训练患者。记 `q_i` 为对患者 i 的交叉拟合教师概率，推荐起点为温度 `T=1`：

\[
L=(1-\lambda)\operatorname{BCE}(y,p_S)
 +\lambda\operatorname{BCE}(q,p_S)+R(\theta),
\quad\lambda\in\{0,0.5,1\}.
\]

在 `T=1` 时，两项 BCE 等价于软目标 `(1−λ)y+λq` 的 BCE。有符号 Logistic 学生可通过对每个训练样本建立正/负两行、赋予软目标对应的 sample weight，调用标准 LogisticRegression 求解；需以梯度/目标一致性测试确认正则尺度。非负 gate 使用成熟优化器求解明确的损失，不另写 PRS 或遗传距离算法。

`λ=0` 是必须保留的同结构真实标签对照。若软标签没有带来增量，可以保留祖源学生而放弃蒸馏主张。温度和更多 λ 值暂不扩大搜索；先检验这三个预定配置。为优化概率质量，学生超参数预定按内层 log loss 选择，AUC 作为并列评价指标。这与教师 benchmark 按 AUC 选择的规则分别登记。

## 无泄漏交叉拟合

最容易被忽略的泄漏，是用“一次全 training 生成的教师 OOF 标签”进行学生内层调参：生成某个内层训练样本软标签的教师，可能见过学生内层验证患者的标签。这会使学生选择间接利用验证标签。

因此每个外层折按以下范围执行：

1. 外层训练集记为 T，外层查询集记为 Q。Q 的疾病标签不进入任何拟合或选择。
2. 学生每个内层划分为 T_fit 和 T_val。在 T_fit 内再交叉拟合教师，生成 T_fit 的软标签；教师的所有 context 都限制在 T_fit。
3. 学生在 T_fit 的真实标签和软标签上训练；在 T_val 的真实结局上选学生参数。禁止教师为了生成 T_fit 软标签而读取 T_val 结局。
4. 完成选择后，在整个 T 内重新交叉拟合教师生成软标签，以选定配置拟合最终学生；在 Q 上预测。
5. 外层教师比较使用全部 T 作为 context。原定 training 使用一套方法共享的患者级五折；乳腺癌在合格女性中执行。未经核验的 KING 连通分量不自动成为新纳入或排除规则；如后续确认亲缘并需更改划分，另建敏感性版本。

教师目标可以按 `训练患者ID hash + 分折 hash + 面板 hash + checkpoint hash + 预处理版本 + seed` 缓存，在相同训练范围下复用。不能只按疾病名或折号复用软标签。该缓存使三个 λ、两个学生容量及多种正则共享教师计算，成本主要由必要的教师上下文决定。

在外层 5 折、学生内层 3 折、教师交叉拟合 3 折时，每疾病需要 `5 × (3×3 + 3 + 1) = 65` 次教师拟合，包括外层教师自身的比较。只有患者、划分、输入和运行配置均一致的预测才可复用；此前 QC/亲缘 OOF 不符合原定队列的缓存条件。这个数量不随学生的 λ/C 网格成倍增加；正式提交前先测一个上下文的运行时间和峰值内存。

## 聚焦遗传增量的辅助蒸馏

如果完整风险的蒸馏主要学到了年龄和祖源基础风险，可以另行检验一个更聚焦 PRS 的目标。在完全相同的交叉拟合上下文中，分别得到完整教师与协变量教师的预测，构造

\[
r_T=\operatorname{logit}(q_{T,full})-\operatorname{logit}(q_{T,cov}).
\]

让学生的遗传项 `g(A,Z)` 逼近 `r_T`，同时保留真实结局的 BCE：`BCE(y, sigmoid(b+g)) + λ Huber(g−r_T)`。该设计有助于避免“概率拟合很好，但祖源权重没有学到遗传增量”的情形。它需要两个教师，计算量约翻倍，因此作为普通概率蒸馏之后的辅助实验。

`r_T` 是两个预测系统的差异，不是已识别的遗传因果效应，也不保证等于完整教师内部的独立 PRS 贡献。需要把这种辅助损失与普通蒸馏、同结构真实标签学生一并比较；只有它提高结局表现或可重复的保真度时才保留。

## 评价与阶段顺序

先完成当前硬标签 benchmark，再从有符号学生开始蒸馏；随后增加非负线性 gate。只有前两步发现容量瓶颈时，才考虑低秩 gate、样条 gate 或更复杂网络。

| 评价 | 需要保存的证据 |
|---|---|
| 疾病预测 | pooled OOF AUC、log loss、Brier、校准、祖源分组人数和病例数 |
| 蒸馏增量 | 同结构、同数据、同预算的 λ>0 对 λ=0 配对差异 |
| 教师保真度 | 概率 MAE、Bernoulli KL、logit 相关、风险排序一致性；不能替代结局评价 |
| 祖源系数贡献 | S1 对 S0、S2 对 S0、S3 对 S1/S2，以及有符号可变对固定系数 |
| 稳定性 | 多 seed 重训练的组合风险/权重曲线；PRS 家族级汇总及相关矩阵 |
| 部署成本 | 固定硬件上的每千例推理时间、内存、模型大小；明确教师缓存与学生独立推理条件 |

权重图只展示 NYU 具有充分覆盖的祖源区域，并叠加样本密度。对低密度区域输出不确定性和适用范围，而不把平滑插值曲线当作可靠外推。三疾病分别报告；单个疾病蒸馏有效不能代表所有疾病有效。

内部结果可支持“在当前 NYU 队列压缩教师并保留一定预测能力”的结论。可迁移性、外部校准及部署临床效用仍需要独立队列。

## 方法定位

祖源 gate 本身已有相近工作。MoEPRS 的官方实现包含 gate 输入、专家和全局协变量接口；因此贡献应聚焦蒸馏的收益、稳定性和部署能力，不能将“祖源调节权重”单独声称为全新概念。[1] TabPFN 局部蒸馏研究提供另一类解释路径；本方案寻求对新患者可独立推理的全局学生，需单独验证容量与保真度。[2]

1. [MoEPRS official model implementation](https://github.com/shz9/moe-prs-paper/blob/main/model/moe.py)。
2. [Interpretable AI with Local Distillation](https://arxiv.org/abs/2608.23538)。
