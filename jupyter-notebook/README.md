# Notebook Index

Use notebooks for exploration and prototype validation. Keep production logic in `src/decipehr/` and `scripts/`.

- `00_competition_contract.ipynb`: extract disease labels, fields, metrics, submission schema, and summary-statistics rules from the official PDFs.
- `01_eda_qc.ipynb`: phenotype, covariate, ancestry, missingness, and genotype QC exploration.
- `02_cv_pt_baseline.ipynb`: prototype P+T parameters and fold-level outputs.
- `03_ldpred2_prscs.ipynb`: prototype stronger PRS methods.
- `04_ensemble_eval.ipynb`: compare out-of-fold predictions and risk stratification.
